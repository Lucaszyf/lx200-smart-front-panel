# LX200 智能面板 — MVP6：虚拟手柄盲视复位

独立、可单独编译烧录的 Arduino sketch，包含 MVP0 + MVP1 + MVP2 + MVP3 + MVP4 + MVP5 + MVP6 阶段的功能。

## 范围

MVP0+MVP1+MVP2+MVP3+MVP4+MVP5全部功能（看门狗、六态识别显示、OLED六行
布局、遥测、A0/A1电气隔离、A2 WiFi透传、B0/B1/B2手柄直通主板、转码引擎+
仲裁注入、下行镜像、时间同步）+

13. **虚拟手柄"强力盲视复位"（需求9）**：新增 `virtual_handset.cpp` 模块。
    每次从非B状态切入 B0/B1/B2 的第一时间，自动盲发5次 ESC/BACK 键（按下
    →保持80ms→松开→间隔60ms，循环5次），把主板强行拉回已知的菜单基线，
    不依赖内存里的上一次状态做叠加推演。等待期间以约1ms粒度持续检查手柄
    是否有新活动，一旦检测到立即中止剩余序列，把控制权交还给物理手柄。

新增 `handset_keycodes.h`，把PDF里全部按键的HEX码集中定义在一处（之前
`transcode_engine.cpp`里只私有定义了用到的N/S/E/W几个，现在有了完整总表）。
`router_bridge.h` 新增两个导出函数供 `virtual_handset.cpp` 复用同一套手柄
仲裁逻辑：`router_bridge_try_inject_byte()`、`router_bridge_handset_idle()`。

**不包含**：完整虚拟手柄状态树（见下方"已知限制"）、BLE/Web远程注入、
NVS配置、WiFi STA模式。

## ⚠️ UART角色映射（重要）

ESP32三路UART外设按实际原理图走线分配角色，跟固件v4/硬件v8文档文字描述
的编号不一致，以原理图为准：

| UART编号 | 角色 | GPIO |
|---|---|---|
| UART0 | 输入选择器(RS232/USB-C/WiFi) | TX=43 RX=44 |
| UART1 | 主板 | TX=17 RX=18 |
| UART2 | 手柄 | TX=4 RX=5 |

## ⚠️ 一个需要你确认的假设，涉及真实操作主板

**需求9原文要求盲发"ESC/BACK"键，但按键码PDF里没有一个键字面上叫这个
名字**（PDF只有ENTER/MODE/GOTO/N/S/E/W/0-9/PREV/NEXT）。经典LX200手柄
的常见设计里，MODE键经常兼任"退出/返回"功能，`handset_keycodes.h`里
**暂时假设MODE键就是ESC/BACK**，用于这个复位序列。

这个假设**有实际风险**：一旦B模式被触发，就会真的连续5次把这个键发给
主板。如果假设错了，可能让主板进入不期望的菜单状态——跟之前"字库缺字符"
那种纯显示层面的假设完全不是一回事，这个会真的操作主板。

**强烈建议**：确认这个假设之前，先不要在实际接了主板的环境里触发B模式
测试这部分；可以先在独立接线（不接主板）的环境下验证宏序列本身的时序、
中断响应逻辑是否正确（观察串口日志），确认ESC/BACK对应的真实按键后，
再接主板实测。

## ⚠️ 已知限制

- **74LVC1G125三态缓冲器在最终原理图里不存在**，上电毛刺保护改为依赖
  ESP32 GPIO复位后默认高阻态 + 主板侧上拉电阻，保护力度弱于原设计。
- **需求9原文还描述了一个更完整的"虚拟手柄状态树"能力**（通过分析手柄↔
  主板双向流量预测当前光标位置和菜单状态，为后续控制提供上下文感知）——
  这需要知道主板菜单系统的完整状态机，跟MVP5提到的"手柄显示协议"是同一
  类缺口（甚至更复杂），本阶段没有实现，只做了"盲发复位宏序列"这个具体、
  可独立验证的子集。
- **⚠️ 协议修正**：手柄按键码文档更正版修复了S/E/W三个键Key-Up码的3处
  笔误（S:0xC3→0xD3　E:0xD5→0xC5　W:0xB7→0xD7，详见`handset_keycodes.h`），
  速率指令（`:RG#`等）已确认复用数字键0/1/4/7的HEX码，不再是占位符。
- **手柄显示协议未知**等MVP5遗留的已知限制仍然存在，
  详见对应阶段说明。

## 编译

- 开发板：ESP32S3 Dev Module
- Flash Size：16MB　**Flash Mode：QIO 80MHz**（选OPI会导致bootloader阶段反复被看门狗打断重启）
- PSRAM：OPI PSRAM
- **USB CDC On Boot：必须选 Enabled**
- 串口波特率：115200

## 验收清单

MVP0+MVP1+MVP2+MVP3+MVP4+MVP5的全部验收项，外加：

- [ ] **先在不接主板的环境下测试**：拨到B0/B1/B2任意一个，串口能看到
      `[virtual_handset]`开头的日志，5次"按下/保持/松开/间隔"节奏正常，
      最终显示"强力盲视复位序列执行完毕"
- [ ] 复位序列执行过程中，手动操作手柄，确认序列会在下一次检查点（最多
      约1ms后）立即中止，串口日志能看到"检测到手柄活动，中止复位序列"
- [ ] 从B0切到B1（或B1切到B2等B系列内部切换），确认**不会**重复触发复位
      序列（只在从非B状态首次进入B状态时触发一次）
- [ ] 从B状态切到A状态再切回B状态，确认复位序列会再次触发
- [ ] 确认ESC/BACK键的真实身份后，再接主板测试，确认5次盲发能让主板从
      任意菜单深度回到主菜单基线
